# Build in Public — Global Indie & One-Person Company Log

A public build journal by a senior Java engineer exploring **AI**, **global micro-SaaS**, and **developer tools** — full-time.

This repository documents the transition from traditional employment to an indie, globally oriented one-person company: market research, product experiments, automation stack notes, and honest weekly reflections.

**Language convention:** Public-facing narrative (README, kickoff, roadmap milestones) is **English**; execution docs (daily SOP, roles, scorecards, templates) are mostly **中文** — same funnel, two audiences (global BIP readers vs. founder ops).

## Why this exists

- **Build in Public** — ship thinking and progress in the open, not only finished products.
- **Global-first** — prioritize English-speaking and worldwide markets over a single local loop.
- **AI-native workflow** — use AI as leverage for research, shipping, and operations as a solo founder.
- **Learning compound** — turn unemployment / career reset into a deliberate, documented path.
