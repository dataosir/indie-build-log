# 交易纪律陪跑 — 咨询包执行单（兴趣轨 · 合法版）

**用途：** 兴趣轨 — 用 **固定价陪跑** 验证「纪律 / 复盘」付费意愿，**不卖票、不荐股、不代操盘**  
**与 TEA 关系：** 交付物围绕 **计划绑定 + 门禁 SOP + 复盘节奏**；TEA 为可选工具，非必须  
**与 GraalVM 关系：** **无协同**；时间上限 **每周 ≤4h**，不抢现金轨 / SaaS 验证  
**前置：** GraalVM 现金轨已启动；或 CEO 书面批准「兴趣轨试点」  
**时间盒：** 首期 cohort **4 周**；单客户交付 **≤6h**（含 4 次 call）  
**Last updated:** 2026-08-30

> 不卖「明天买什么」，卖 **「证明你有没有按计划交易」的流程**。  
> 不卖预测，卖 **可审计的纪律系统** —— 与 TEA「准入引擎」叙事一致。

---

## 0. 启动前快筛（5 个 Yes 才接单）

- [ ] 书面免责声明已就绪（§8 模板）— 客户签字 / 邮件确认  
- [ ] **明确拒绝**：荐股、代操盘、代下单、收益承诺、实时喊单  
- [ ] TEA 或等价工具 **仅作纪律演示**，不保证策略盈利  
- [ ] 首期 **≤5 个客户**（cohort 制，控制支持负担）  
- [ ] 本周 GraalVM 现金轨 + SaaS 验证 **≥ 总工时 50%**  

**任一 No → 不接单。**

## 1. 定位与 ICP（买家，不是「所有股民」）

### 1.1 一句话 Offer

```text
For: 已有自己交易规则、仍常冲动开仓或跳过复盘的主观交易者（A 股为主）
Pain: 知道纪律重要，但盘中管不住手、盘后不会复盘、不知道哪道闸门该调
Outcome: 4 周内建立「计划绑定 + 固定窗口 + 周复盘」可执行 SOP — 不是选股建议
Price: ¥2,999–5,999 / 4 周（固定价 cohort）— 不卖信号
NOT for: 要荐股的人、零基础小白、指望跟单盈利的人
```

### 1.2 ICP 画布（复制填写）

| 字段 | 内容 |
|------|------|
| **谁刷卡** | 有 1–3 年交易经验、有自己规则、仍违反计划者 |
| **触发时刻** | 连续冲动开仓；复盘发现「又没按计划」；想系统化但不知从何改 |
| **已在付什么** | 行情软件会员、课程、自己的亏损（隐性成本） |
| **愿付区间** | **¥2,999–5,999 / 4 周**（流程陪跑，非按笔分成） |
| **在哪出现** | 雪球纪律帖、集思录、交易复盘社群、熟人介绍 |

### 1.3 与 TEA / 主业的关系

| 轨道 | 角色 | 时间上限 |
|------|------|----------|
| **GraalVM 现金轨** | 主业收入 | 50%+ |
| **TEA 开源** | 样本积累 + 工程内容 | ≤2h/周 |
| **本陪跑** | 验证纪律付费 + 个人品牌 | ≤4h/周 |

**规则：** 陪跑客户 ≠ TEA 商业客户；不把 TEA 包装成「稳赚工具」。

## 2. SKU 与定价（固定价，两档）

直到 **第 3 单完成** 前，**只推一档**（建议 Standard），避免选择疲劳。

### SKU A — 纪律 SOP 搭建（主推 · Standard）

| 项 | 内容 |
|----|------|
| **价格** | **¥3,999** 固定价（4 周 cohort，微信/支付宝；不开票或按当地规定） |
| **人数** | 每期 **3–5 人**（小班，同期开营） |
| **交付** | ① 个人交易计划模板 ② 每日/每周复盘表 ③ TEA 或 Notion 配置辅导 ④ **4 × 45min** 周 call ⑤ 结业「纪律自查清单」 |
| **不含** | 个股分析、买卖时点、代下单、收益保证、7×24 答疑 |

### SKU B — 1v1 深度陪跑（Premium）

| 项 | 内容 |
|----|------|
| **价格** | **¥5,999** 固定价（仅 1v1，每期最多 **2 人**） |
| **增量** | 多 2 次 call；协助定制门禁阈值；4 周每日异步文字复盘（限 15min/天回复） |
| **不含** | 同上 — **绝不碰荐股** |

### 定价决策表（CEO 勾选）

- [ ] **主推 SKU A** — 小班可复制、交付边界清晰  
- [ ] 主推 SKU B — 仅当有明确 1v1 需求且 ≤2 人排队  

**收款方式：** 开营前 **100% 预付**；开营后不退款（免责声明写明）。

## 3. 交付范围（Scope）— 写进协议 / 微信确认

### 3.1 包含（In scope）

- [ ] 交易 **计划** 模板（标的池、仓位、止损原则 — **由客户自己填**）  
- [ ] **复盘** 节奏：每日 3 问 + 每周归因表  
- [ ] 门禁概念讲解：计划绑定、时间窗、单日限额（对齐 TEA 哲学，可用任意工具实现）  
- [ ] TEA `seed-plan` / `review` / `weekly` 工作流 **演示与配置辅导**（可选）  
- [ ] 4 次结构化周 call（见 §4.3 议程）  

### 3.2 不包含（Out of scope）— 必须书面排除

- [ ] 任何 **具体股票买卖建议**、目标价、仓位推荐  
- [ ] 代客下单、代操账户、分润跟单  
- [ ] 收益承诺、胜率保证、「稳赚」宣传  
- [ ] 投资顾问牌照范围内的服务（本服务 = **纪律与流程咨询**）  
- [ ] 7×24 盘中答疑、实时喊单  
- [ ] 医疗 / 心理健康咨询  

### 3.3 交付物清单模板

```markdown
## 结业交付 — [客户昵称] — [日期]

### 已建立
- [ ] 书面交易计划 v1（客户自填，陪跑方未改标的）
- [ ] 复盘表模板（日 / 周）
- [ ] 纪律自查清单（10 条以内）
- [ ] 工具配置截图（TEA / Notion / 自选）

### 4 周记录
- Week 1: 计划是否每日更新 Y/N
- Week 2: 违反计划次数 ___
- Week 3: 复盘完成率 ___%
- Week 4: 客户自评纪律分 /10

### 免责声明确认
- [ ] 客户已读并确认 §8 免责声明（截图 / 邮件）
```

## 4. Week 1–4 — 交付执行（可勾选）

### Week 0：招募（开营前 1 周）

- [ ] 发招募帖（§5.1 模板）— **强调非荐股**  
- [ ] 筛选问卷：5 题（见 §4.1）  
- [ ] 拒绝「要荐股」申请者（§5.3 话术）  
- [ ] 收款 + 免责声明签字  
- [ ] 建群（仅流程通知，**不在群内报票**）  

### 4.1 筛选问卷（5 题）

| # | 问题 | 淘汰条件 |
|---|------|----------|
| Q1 | 你是否有书面交易计划？ | 完全无且不愿写 → 劝退 |
| Q2 | 上周是否违反过自己的规则？ | 答「从不」→ 可能非 ICP |
| Q3 | 你期望从陪跑中得到什么？ | 出现「荐股」「代操」→ **拒绝** |
| Q4 | 可投入复盘时间？每周 ≥3h？ | <1h → 劝退 |
| Q5 | 能否接受「不保证盈利」免责声明？ | No → **拒绝** |

### Week 1：计划与门禁

- [ ] 发放计划模板 + 复盘表  
- [ ] Call #1（45min）：讲清「计划绑定」；客户 **自己** 填计划  
- [ ] 作业：连续 3 天写日复盘  

### Week 2：执行与违反记录

- [ ] Call #2：回顾违反计划案例 — **只谈行为，不谈标的**  
- [ ] 引入时间窗 / 单日限额概念  
- [ ] 作业：记录每次「想冲动开仓」的时刻与触发因素  

### Week 3：归因与工具

- [ ] Call #3：TEA 或 Notion 演示（可选）  
- [ ] 帮客户读自己的 **违反模式**，不给新股票  
- [ ] 作业：完成 1 次周复盘报告  

### Week 4：固化与结业

- [ ] Call #4：纪律自查清单定稿  
- [ ] 问续费意愿（§6）— 不硬推  
- [ ] 发结业交付物（§3.3）

```text
不适合：要荐股、要代操、要稳赚的人

你会得到：
· 交易计划 + 日复盘 + 周归因模板
· 4 次结构化复盘 call（不讲个股买卖）
· 可选：TEA 准入引擎配置辅导（开源纪律工具）

¥3,999 / 4 周 · 开营前全额预付
免责声明：学习/纪律用途，非投资建议，不保证盈利

报名：私信「纪律」+ 简短自述（交易年限、最大痛点）
```

```text
感谢信任。本陪跑只做纪律与复盘流程，不提供任何买卖建议或代操。
```

```text
我在做一个小班「交易纪律陪跑」试点，帮有规则的人把计划和复盘落地。
明确不做荐股。你若或朋友有「管不住手」的痛点，可以聊聊是否 fit。
```

## 6. 续费与产品化 Gate

| 信号 | 动作 |
|------|------|
| 首期 0 人报名 | **Kill 陪跑**；只保留 TEA 自用 + 开源 |
| 报名 <3 人 | 延期或合并到下期，不降价 |
| 结业 ≥2 人愿续 ¥1,999/月（轻答疑） | 考虑第二期 + 写 scorecard |
| 结业 ≥3 人愿为「自动化复盘」付 ¥99/月 | 评估 B3 Global journal — **GraalVM 有收入后** |
| 任何客户投诉「亏了因为你没荐对」 | 立即终止 + 强化免责声明 |

## 7. 时间分配与 CEO Gate

| Runway | 陪跑时间上限 | GraalVM 现金轨 |
|--------|--------------|----------------|
| < 6 个月 | **0h** — 不做陪跑 | 70%+ |
| 6–12 个月 | ≤4h/周 | 50%+ |
| > 12 个月 | ≤6h/周 | 按 roadmap |

**并行产品铁律：** 陪跑 **≠** 第二条 SaaS 产品线；只是兴趣轨验证。
