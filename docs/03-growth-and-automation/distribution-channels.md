# Distribution Channels — $0 Ad Budget Cold Start

**Audience:** Global indie founder, English-first  
**Constraint:** Zero paid ads until after first revenue (then reinvest deliberately)  
**Last updated:** 2026-08-28

> 获客不是“发一篇宣传”，而是可重复的触达节奏。  
> Distribution is a cadence system — not a single launch post.

---

## 1. Channel Strategy Overview

| Priority | Channel | Job to be done | Cash proximity |
|----------|---------|----------------|----------------|
| P0 | **Build in Public** (GitHub + X) | Trust + weekly reach | Medium |
| P0 | **Niche Reddit / forums** | Problem-aware buyers | High if done right |
| P1 | **Product Hunt** | Launch spike + backlinks | Medium (one-shot) |
| P1 | **SEO / long-form** | Compounding inbound | Slow then high |
| P2 | Indie newsletters / directories | Borrowed audience | Medium |
| P2 | HN / Dev.to / Hashnode | Dev-tool awareness | Variable |
| Avoid early | Generic Facebook/IG ads, broad LinkedIn spray | Burn cash/time | Low without offer-market fit |

**Rule:** Pick **one P0 daily habit** + **one P1 campaign per month**. Depth beats channel FOMO.

## 2. Build in Public — GitHub + X Cadence

### 2.1 Positioning

You are not “posting updates.” You are publishing a **public operating system**: decisions, metrics, kills, and ships. That attracts other builders **and** early adopters who trust operators.

### 2.2 GitHub rhythm (this repo)

| Cadence | Action | Asset |
|---------|--------|-------|
| Weekly | Indie log entry | `docs/04-indie-log/YYYY-MM-DD-*.md` |
| Per experiment | Niche / offer notes | `01` / `02` docs |
| Per ship | Tag release or clear README status | Badge: “Week N · $X revenue” |
| Ongoing | Issues as public TODO | Invite feedback |

**README status line (keep fresh):**

```text
Status: Week 3 · Waitlist 42 · Revenue $0 · Next: pre-sale landing
```

### 2.3 X / Twitter rhythm (English)

| Day | Post type | Example angle |
|-----|-----------|---------------|
| Mon | Metric Monday | “Week 2: 12 interviews, 0 sales. Killing idea B.” |
| Tue | Build teaser | Loom / screenshot of landing — with **price** |
| Wed | Lesson thread (5–8 tweets) | Funnel stage failure analysis |
| Thu | Engagement | Reply 20–30 min in indie/SaaS/AI tool threads |
| Fri | Ship / ask | “Would you pay $49/mo for X? Reply yes/no + why” |
| Sat | Optional long | Cross-post blog/Dev.to |
| Sun | Plan | Next week’s **one** commercial KPI |

**Hard rules:**

1. Every week must include **one ask** (feedback, waitlist, or buy).  
2. No pure motivation posts.  
3. Pin a tweet with offer + link when landing is live.  
4. Spend ≥ **40%** of X time **replying**, not broadcasting.

### 2.4 Content that converts vs vanity

| Converts | Vanity |
|----------|--------|
| Price + who it’s for | Aesthetic screenshots only |
| Customer language quotes | “Excited to announce” |
| Public kill decisions | Engagement bait polls with no offer |
| Before/after workflow | Tool logo salad |

### 2.5 KPI for BIP (weekly)

| Metric | Early target |
|--------|--------------|
| Posts published | ≥ 5 |
| Meaningful replies received | ≥ 10 |
| Profile → link clicks | Track via UTM `?utm=x` |
| Waitlist from BIP | ≥ 5 / week once landing exists |

## 3. Product Hunt — First Launch Playbook

### 3.1 When to launch

Launch on PH **only when**:

- Landing is live with clear outcome + price or trial  
- You can demo in **60 seconds** (GIF/Loom)  
- You can be online for **launch day** (hunter + maker comments)  
- You have a small warm circle (BIP followers, indie Discord) ready to **try**, not just upvote empty

Do **not** launch a vapor repo with no usable wedge.

### 3.2 Timeline (T-14 → T+7)

| When | Actions |
|------|---------|
| T-14 | Claim maker account; draft tagline (≤60 chars), description, gallery |
| T-10 | Record demo; prepare first comment (story + link + ask) |
| T-7 | Soft BIP: “Launching on PH next week — what should I clarify?” |
| T-2 | Confirm hunter (or self-hunt); schedule assets |
| T-0 (Tue–Thu PT ideal) | Launch 12:01 AM PT; reply to **every** comment in first 8–12h |
| T+1 | Thank-you post; collect emails; fix top objections |
| T+7 | Write teardown in indie log: rank, traffic, signups, revenue |

### 3.3 Asset checklist

- [ ] Logo 240×240  
- [ ] Gallery: problem → product → outcome (3–5 images)  
- [ ] Tagline focused on **outcome**, not category  
- [ ] First comment: founder story + who it’s for + **price**  
- [ ] Topics: relevant niches only (max signal)  
- [ ] Link with UTM `utm_source=producthunt`

### 3.4 PH anti-patterns

- Asking for upvotes without product value  
- Ignoring comments  
- Launching Monday/Friday casually without support window  
- “AI platform for everyone” tagline

### 3.5 Success criteria (realistic for first launch)

| Outcome | Good enough |
|---------|-------------|
| Upvotes | Not the goal |
| Signups / trials | ≥ 50 |
| Paying | ≥ 1 (ideal) or ≥ 10 high-intent emails |
| Learning | Top 5 objections documented |

## 4. Reddit — Vertical Penetration (High Intent)

### 4.1 Mindset

Reddit punishes ads and rewards **helpful specificity**. Infiltrate as a peer solving the same pain — then soft-link your tool when it’s genuinely on-topic.

### 4.2 Subreddit selection criteria

| Filter | Pass |
|--------|------|
| Buyers present | Freelancers, founders, specialists with budget |
| Problem threads exist weekly | Not only memes |
| Self-promotion rules readable | Follow them strictly |
| Mod culture | Not instant ban on any link |

Examples by product type (illustrative — verify rules):

- Dev tools: `r/devops`, `r/ExperiencedDevs`, `r/java`, `r/selfhosted` (careful)  
- Indie SaaS: `r/SaaS`, `r/Entrepreneur`, `r/smallbusiness`, `r/IndieBiz`  
- AI tools: niche workflow subs > mega `r/ChatGPT` spam

### 4.3 30-day Reddit system

| Week | Focus |
|------|-------|
| 1 | Lurk + comment only; save 20 pain threads |
| 2 | Write 5 high-effort answers; no product link |
| 3 | One “I built X for this exact problem” post **where rules allow** |
| 4 | Repeat best-performing thread pattern; DM only if user invites |

**Comment template:**

1. Restate their constraint  
2. Give a usable fix **without** your product  
3. Optional: “I scripted this / open-sourced notes here” + link  
4. Offer to share the template

### 4.4 KPI

| Metric | Target |
|--------|--------|
| Helpful comments / week | ≥ 10 |
| Thread saves (pain language) | ≥ 5 / week |
| Profile visits / link clicks | Rising week over week |
| Conversions | Track UTM `utm_source=reddit` |

### 4.5 Ban-risk rules

- Never copy-paste the same promo  
- Never brigades from alts  
- Disclose affiliation when linking your product  
- Prefer answer quality over link frequency (max ~1 promotional post / 2 weeks / sub)

## 5. Secondary $0 Channels (use after P0 is habitual)

| Channel | Play | Cadence |
|---------|------|---------|
| Indie Hackers | Process posts + offer link in body | 2 / month |
| Dev.to / Hashnode | “How I validated X in 14 days” | 1 long-form / month |
| Directories | Submit once product is buyable (There’s An AI For That, etc.) | Batch day |
| Newsletter swaps | Trade with similar-sized indie lists | After 200+ emails |
| Cold email (ethical) | 20 highly personalized / week to ideal buyers | Ongoing experiment |
| GitHub Awesome-lists / topics | Earn star via usefulness, not spam PRs | Opportunistic |

---

## 6. UTM & Analytics (keep dumb)

Minimum:

- Landing: Plausible / Umami / GA4 — pick one  
- Links: `utm_source` + `utm_campaign=weekN`  
- Weekly log table: source → visits → waitlist → paid

Without attribution, you will romanticize the loudest channel instead of the paying one.

---

## 7. Weekly Distribution OS (checklist)

```text
[ ] 5 BIP posts (X) + 1 GitHub log update
[ ] 10 Reddit/forum helpful replies
[ ] 20 min engage in 1 niche Discord/Slack (if any)
[ ] 1 outbound experiment (email or DM) with offer
[ ] Update funnel numbers in roadmap doc
[ ] One public “ask” with price or waitlist CTA
```

**Time budget suggestion (solo):**  
- 40% distribution / conversations  
- 30% validation assets (landing, demos)  
- 20% product only after Gate B  
- 10% admin / payments / legal lite
