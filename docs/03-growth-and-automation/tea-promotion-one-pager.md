# TEA — 对外推广 One-Pager（工程向 · 准入而非荐股）

**用途：** 对外介绍开源项目 **TEA**（`xjb_trader`）— 适合 README 置顶、掘金/知乎技术文、GitHub About  
**仓库：** https://github.com/dataosir/xjb_trader  
**受众：** 规则型主观交易者、量化爱好者、Python 工程师 — **不是**「要荐股」的散户  
**Last updated:** 2026-08-30

> **一句话：** TEA 是 A 股 **交易准入引擎** — 默认「不买」，只有道法术三层同时通过，才放行一次开仓评估。  
> **不是选股软件，不自动下单，不预测涨跌。**

---

## 1. 适合谁 / 不适合谁

| ✅ 适合 | ❌ 不适合 |
|---------|-----------|
| 有书面交易计划、仍管不住手的规则型交易者 | 要「明天买哪只」荐股的人 |
| 想学习「纪律门禁」怎么工程化实现的开发者 | 要自动跟单、券商 API 对接的人 |
| 接受「大量日子输出 EMPTY（不买）」的人 | 不能接受空仓、追求每天出手的人 |
| 愿意自己下单、自己承担盈亏的人 | 指望工具保证盈利的人 |

---

## 2. 我们解决什么问题

**痛点：** 冲动开仓、无计划交易、复盘缺失、选股器给一堆票反而更难管住手。

**TEA 的做法：**

```
默认答案 = 不买（EMPTY）
     ↓
道（市场天气）— 情绪、周期、仓位姿态
     ↓ 串联否决
法（纪律门禁）— 计划绑定、时间窗、单日限额、连亏冷却
     ↓ 串联否决
术（个股共振）— 评分 + VETO，非加权凑票
     ↓
仅当三层全过 → 才评估「这一笔够不够资格」
```

**与选股器的区别：**

| 常见选股器 | TEA 准入引擎 |
|------------|--------------|
| 输出一堆候选 | 默认 **EMPTY**，宁缺毋滥 |
| 加权打分，分高就买 | **串联否决**，一层挂全挂 |
| 盘中随时提示 | **计划绑定** + 14:00–14:45 唯一买入窗口 |
| 黑盒策略 | `seed_trace` / accumulator **可审计** |

## 3. 核心能力（对外可讲）

| 能力 | 说明 |
|------|------|
| **计划绑定** | 无有效计划 → 禁止评估、禁止买入 |
| **道法术三层** | 市场天气 × 纪律门禁 × 个股共振 |
| **种子四步流** | 14:30 写次日计划 → T+1 窗口执行 |
| **五源行情降级** | 东财/新浪等多源，断线可降级 |
| **零依赖 Python** | 标准库实现，**352/352 自测** |
| **MIT 开源** | 可 fork、可审计、无闭源黑箱 |

**每日节奏（简版）：**

| 时刻 | 动作 |
|------|------|
| 14:30 | `seed-plan` — 写次日计划 |
| T+1 14:00–14:45 | **唯一买入窗口** — `run <代码>` |
| 收盘后 | `review` — 跟涨回填 |
| 周五 | `weekly` — 纪律自查 |

## 4. 技术卖点（开发者向）

适合技术社区推广的第二叙事：

- **零第三方依赖** — 仅 Python 3.8+ 标准库；可选 `requests` 加速
- **352 项离线自测** — `./run.sh selftest`，CI 绿灯可引用
- **原子落盘** — `seed_records.jsonl` / `accumulator.jsonl` 可回溯
- **配置驱动** — `tea_config.json` 410 项，可灰度调参（**无样本禁止乱调**）
- **跨平台** — Linux / macOS / Windows，可打 `.app` / `.exe`

**推荐 GitHub Topics：** `a-share` `trading` `risk-management` `python` `cli` `discipline`

## 5. 快速开始（复制到文章）

```bash
git clone https://github.com/dataosir/xjb_trader.git
cd xjb_trader
./run.sh selftest          # 验证环境
./run.sh                   # 数字菜单
./run.sh weather           # 看市场天气
```

**两周空跑 eval（推荐给新用户）：**

1. **不实盘** — 只跑 `seed-plan` + `review`，记录 EMPTY 天数  
2. 读 `reports/SEED_*.md` — 理解漏斗为何否决  
3. 周五跑 `weekly` — 填纪律自查  
4. 两周后自问：**「这套门禁是否让我少犯了冲动单？」** — 不是问赚了多少
