# 90-Day Roadmap — Unemployment → First USD Revenue

**Start date:** 2026-08-28 (Day 0 / Kickoff)  
**End date:** 2026-11-25 (Day 90)  
**Primary success metric:** ≥ **$1 USD** received from a real customer for a defined offer  
**Secondary:** Path to **$100 MRR** or **$500** cumulative one-time clear and documented  
**Last updated:** 2026-08-28

> 90 天不是用来“学完再开始”的，而是用来完成漏斗闭环的。  
> Day 90 is a closed-loop deadline — not a learning holiday.

---

## 1. North Stars & Kill Criteria

| Type | Metric | Target by Day 90 |
|------|--------|------------------|
| Revenue | Gross USD received | ≥ $1 (stretch: $100 MRR / $500 total) |
| Validation | Interviews or deep problem convos | ≥ 25 |
| Demand asset | Waitlist emails **or** pre-sale buyers | ≥ 50 emails **or** ≥ 3 paid |
| Distribution | Public shipping weeks | ≥ 12 weekly log entries |
| Focus | Parallel product bets in build | **≤ 1** active build |

**Company-level kill / pivot triggers:**

- Day 45: still **no** priced landing and **no** 10 interviews → stop coding, only research/sales  
- Day 60: priced offer live but **0** paid intent (buy clicks / “I’ll pay” replies) → change niche or offer, not UI polish  
- Day 90: $0 revenue → full retrospective + new 90-day bet (do not quietly extend the same zombie product)

```text
Days 1–30   FOUNDATION     Research → scorecard → offer draft → landing
Days 31–60  VALIDATION     Pre-sale / concierge → first $ attempts → PH prep
Days 61–90  MONETIZE       Close first USD → harden fulfillment → decide next bet
```

## 3. Phase Milestones (quantified)

### Phase 1 — Days 1–30: Foundation

| ID | Milestone | Definition of Done | KPI |
|----|-----------|--------------------|-----|
| F1 | Scorecard live | ≥ 10 ideas scored; top 3 ranked | Doc committed |
| F2 | Niche teardown | Competitors + prices for top niche | 1 teardown MD |
| F3 | Interviews | ≥ 10 problem conversations | Notes with budget quotes |
| F4 | Offer v1 | Who / pain / outcome / price written | 1-pager |
| F5 | Landing live | Public URL + price + CTA | ≥ 1 UTM link shared |
| F6 | Payment rails | Stripe or MoR account can take USD | Test mode → live ready |
| F7 | BIP cadence | Weekly log + ≥ 5 X posts / week | Habit proven |

**Phase 1 exit gate:** F5 + F3 mandatory. Prefer F6.

### Phase 2 — Days 31–60: Validation

| ID | Milestone | Definition of Done | KPI |
|----|-----------|--------------------|-----|
| V1 | Waitlist traction | ≥ 30 emails **or** ≥ 3 pre-sale conversations | CRM/Notion list |
| V2 | Pre-sale or concierge | Checkout OR manual invoice offered | ≥ 10 people saw price |
| V3 | Paid intent | ≥ 5 “buy” clicks or written pay commits | Logged |
| V4 | First delivery dry-run | Fulfill outcome once (even unpaid pilot OK if scheduled paid next) | Checklist exists |
| V5 | Channel depth | Reddit system running; BIP uninterrupted | Weekly channel KPIs |
| V6 | PH readiness **or** skip rationale | Assets ready **or** written “not yet” with date | Checklist |

**Phase 2 exit gate:** V2 + V3. Coding allowed only to unblock delivery of paid/pre-sold promise.

### Phase 3 — Days 61–90: Monetize

| ID | Milestone | Definition of Done | KPI |
|----|-----------|--------------------|-----|
| M1 | **First USD** | Money in Stripe/MoR from customer | ≥ $1 |
| M2 | Fulfillment SLA | Access/delivery ≤ 48h documented | 100% on-time for buyers |
| M3 | Retention / refund lesson | 1 follow-up survey or call | Notes |
| M4 | Unit economics sketch | COGS + price → margin estimate | ≥ 70% target path |
| M5 | Next 90-day bet | Double-down / adjacent SKU / kill | Written decision |
| M6 | Public teardown | Day-90 post in this folder | MD + metrics table |

**Phase 3 exit gate:** M1 required for “success.” M5 required regardless.
