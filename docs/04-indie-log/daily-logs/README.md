# Daily Logs

**Purpose:** 每日 SOP 实例化 + 每周 scorecard 存档  
**How to use:**

1. **Daily:** 复制 [`../../daily_sop.md`](../../daily_sop.md) 到 `YYYY-MM-DD.md`，或在内嵌 SOP 中填写  
2. **Weekly (Sunday):** 新建 `YYYY-MM-DD-weekN-scorecard.md`，从 [`../roadmap-and-milestones.md`](../roadmap-and-milestones.md) §5 复制模板  

**Language:** 执行日志以中文为主；对外 BIP 摘录可英文发布。
